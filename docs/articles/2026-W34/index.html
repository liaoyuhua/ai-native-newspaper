把对齐揉进黏土：为什么 post-training 只剩绑定人格

从 token zero 装进一个声音，而不是最后刷一层漆

从刷漆到揉黏土：对齐为什么不能只靠最后一步

以宪法AI（CAI）为例，后训练过程包含监督学习和强化学习阶段，用一份原则清单代替人工标注来约束模型。这些方法背后的大致逻辑是：模型在预训练阶段已经吸收了海量文本，后训练阶段再叠加对齐信号。[1]

问题在于，这层叠加可能很薄。有研究提示，价值观只是在预训练模型之上的薄弱叠加层，后续仍可能出现错位。[2]

SPP 的思路是将价值观前置到预训练阶段：基于一份书面价值观清单（宪法）生成第一人称价值反思，再把这些反思作为预训练文档混入原始语料，使模型在预训练阶段就接触对齐信号。

下表对比 SPP 借用的两个机制：

机制 核心动作 输出
宪法合成反思（CAI） 用宪法引导模型自我批判与修订，生成无害响应[1] 修订后的响应
合成指令预训练（Instruction PT） 用指令合成器把原始文本变成指令-响应对，增强预训练语料 监督多任务预训练信号

这两张卡合起来，就是 SPP 把宪法反思按指令格式注入预训练文档的技术基础。下面分别展开。

宪法反思：从一条原则到语料里的一种声音

CAI 的起点是一份短的原则清单（constitution），这是唯一的人类监督信号。监督学习阶段：从初始模型采样响应，然后按照宪法生成自我批判和修订，再用修订后的响应微调模型。据报道，后续还会进行强化学习阶段，以进一步优化模型行为。[1] 关键点：CAI 本身包含监督学习和强化学习阶段，但它的中间产物——宪法引导的自我批判和修订——正是 SPP 需要的第一人称价值反思。SPP 把这个反思挪到预训练文档里，作为语料的一部分。这意味着，SPP 不是抛弃 CAI，而是把 CAI 的数据生成过程前置到预训练数据构造中。[1]

合成指令对：把预训练从模仿升级成监督多任务

Instruction Pre-Training 的核心是把原始语料转化成监督多任务数据。据报道，它先构造一个指令合成器：利用开源模型，输入一段 raw text，输出一组 instruction-response pairs。[3] 然后对大规模原始语料进行增强，在实验中合成了2亿条 instruction-response pairs，覆盖40+任务类别。[3] 这些合成对随后被用于增强预训练语料；相关实验初步显示，该方法在后续指令微调中收益更大。 SPP 借用的正是这个框架：将宪法反思包装成 instruction-response pairs，然后混入预训练文档。这样，价值反思不再是外部附加，而是预训练任务的一部分。从 token zero 开始，模型就学习了一个“根据文本生成价值反思”的监督信号，从而把目标人格作为原生任务之一内化。

判断：post-training 只剩一件事——绑定那个已经存在的声音

post-training 的职责从“安装价值观”降级为“绑定一个已经存在的助手人格”，即 persona binding。这不是说 post-training 不重要，而是它的角色变了：它只是把一个标签路由到预训练中已经形成的人格。

未解风险有三：一是规模外推，3B/500B 的结果能否外推到百 B 参数、数十 T token 尚未可知；二是人格写死后的可调整性，一个在预训练阶段固化的人格是否更难用少量 SFT 改变？三是 token zero 与 mid-training 差异的机制未明，论文展示了现象，但缺少可核对的解释。这些是下一步需要回答的问题。

开放问题

  • 规模外推：论文只在 3B/500B token 上验证，且发现优势随预训练预算增长——这一趋势能否外推到前沿规模（百 B 级参数、数十 T token），以及它在更强 RLHF 型 post-training 之后是否仍保持，尚无证据。
  • 可塑性 vs 刚性的权衡：一个在 pretraining 阶段写死的人格，事后是否更难调整或再对齐？『绑定』是否会削弱后来用少量 SFT 改变行为的能力（即人格绑定的另一面是锁定）？论文未回答。
  • 机制未解：为什么同一份反思数据在 token zero 与 mid-training 效果迥异（表示形成时序？优化动力学？还是数据排序/遗忘效应？）——论文展示了现象，但缺少可核对的内在机制解释。
